# hiimnhan.github.io

Personal site built with [Quartz v5](https://quartz.jzhao.xyz). Pushing to `main` deploys it to GitHub Pages (`.github/workflows/deploy.yml`).

## Setup (once per machine)

```bash
npm ci
npx quartz plugin install --from-config
```

Requires Node 22.22+.

## Preview locally

```bash
npx quartz build --serve
```

Open http://localhost:8080. Pages rebuild when you save; after editing `quartz.config.yaml` or a plugin, stop and restart the command. If a style change doesn't show, hard-reload (Cmd+Shift+R).

## Publish notes from the Obsidian vault

Only notes you mark are published. The vault itself never goes into this repo.

1. In Obsidian, add the property `publish: true` to the note.
2. Copy marked notes into the site:

   ```bash
   npm run publish-notes
   ```

   This regenerates `content/notes/` from the vault (default `~/personal/brainrot`; override with `VAULT=/path npm run publish-notes`). Embedded images and PDFs come along. Notes you un-mark are removed. It prints what it published.
3. Preview, then commit and push:

   ```bash
   git add content/notes
   git commit -m "Publish notes"
   git push
   ```

Notes:

- Two published notes can't share a filename, and a note can't be named `index.md` (reserved for the Notes page). The script stops with an error if either happens.
- Each note gets the address `/notes/<note-name-in-kebab-case>` (e.g. `Mechanisms of (mis)allocating Credit` → `/notes/mechanisms-of-mis-allocating-credit`). To choose your own, add `permalink: notes/whatever` to the note.
- Links to notes you haven't published show as plain text.
- Side-Notes sidenotes, math, and the Callout Studio callouts (lemma, proof, proposition, theorem, definition) render as in Obsidian.

## Edit the other pages

| What | File |
|---|---|
| Home page (bio, links, photo) | `content/index.md` |
| Research (papers) | `content/research.md` |
| Notes landing text | `content/notes/index.md` |
| CV | `content/cv.pdf` (replace the file) |
| Paper PDFs | `content/papers/` (use lowercase-hyphenated filenames, no spaces) |
| Profile photo | `content/images/me.jpg` |

To add a paper, copy an existing block in `content/research.md`:

```markdown
## Paper title

Author names  
*Venue, Year*

[PDF](papers/file-name.pdf) · [Code](https://github.com/...)

> [!abstract]- Abstract
> Abstract text.
```

## Customise

- **Left sidebar links:** `options.links` under `./plugins/site-nav` in `quartz.config.yaml`.
- **Footer links:** `options.links` under `@quartz-community/footer` in `quartz.config.yaml`.
- **Styles** (sidenotes, callouts, fonts, photo): `quartz/styles/custom.scss`.
- **Theme:** `@quartz-themes/core` in `quartz.config.yaml` (currently Tokyo Night, dark).

## Repo layout

- `content/`: site pages and files. `content/notes/` is generated by `publish-notes`, apart from `index.md`.
- `scripts/publish-notes.mjs`: copies `publish: true` notes from the vault.
- `plugins/sidenotes/`: renders Side-Notes `<span class="sidenote">` as margin notes; fixes Obsidian-only math quirks.
- `plugins/site-nav/`: the left sidebar link list.
- `quartz/`, `quartz.config.yaml`: Quartz itself and its config.

## Deployment

GitHub Pages must be set to **Settings → Pages → Source: GitHub Actions**. Every push to `main` builds and deploys; check progress under the repo's **Actions** tab.
